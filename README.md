# ShowTime — Event Ticketing Platform

A responsive React.js frontend for discovering events and booking seats with live availability states.

## Features
- Event discovery with search and category filters
- Responsive event cards and details
- Interactive 8 × 10 seat map
- Available, selected and booked seat states
- Dynamic booking total and confirmation flow
- Mobile, tablet and desktop responsive layout
- Component-style React architecture and local state management

## Tech Stack
React.js · JavaScript · HTML · CSS · Vite · Lucide React

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Project
Built as a frontend portfolio project demonstrating React state management, conditional rendering, responsive CSS and interactive booking UX.
